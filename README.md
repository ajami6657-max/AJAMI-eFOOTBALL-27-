# AJAMI eFOOTBALL 27

An original Android football-game project. The repository begins with a buildable OpenGL ES prototype and will grow in staged milestones toward an offline 11v11 football game.

## Current milestone
- Android/Kotlin application foundation
- OpenGL ES 2.0 pitch renderer with player markers and ball
- GitHub Actions debug APK build
- No network permission or online account requirement in this initial prototype

## Build
Run **Android APK** from the Actions tab. The workflow uploads a debug APK artifact.

## Roadmap
1. Buildable Android foundation and match-pitch prototype
2. Touch controls, player movement, ball physics and camera
3. Match rules, goalkeeper, AI and 11v11 simulation
4. Teams, leagues, cups and national competitions using legally usable data/assets
5. PES-inspired Game Plan and Master League systems
6. Offline Persian commentary using original/licensed voice assets
7. Performance and device testing

## Status
This is an early development prototype, not a finished football game. Full 3D player models, match AI, league databases, commentary and career systems remain to be built. Club/player branding and voice assets will be original or properly licensed.
